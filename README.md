# Budget – iPhone app (Windowsról, ingyen)
1. GitHub: új PUBLIKUS repo (a macOS fordítás publikus repónál ingyenes). Töltsd fel az összes fájlt, a rejtett .github mappával együtt.
2. Actions fül → "Build IPA" → várj ~5-10 percet → Artifacts → Budget-ipa letöltése → kicsomagolod → Budget.ipa
3. Windowson: Sideloadly (sideloadly.io) + iTunes és iCloud (apple.com-ról, nem Microsoft Store). iPhone USB-n, húzd be a Budget.ipa-t, add meg az Apple ID-d, Start.
4. iPhone: Beállítások → Adatvédelem és biztonság → Fejlesztői mód (be) → újraindítás; Általános → VPN és eszközkezelés → saját Apple ID megbízhatóvá tétele.
Ingyenes Apple ID: 7 naponta újra kell telepíteni (AltStore ezt Wi-Fin automatikusan megteszi, ha a gép be van kapcsolva).
